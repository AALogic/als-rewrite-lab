# Type 3 Current-Path Relocation Evidence

Status: implemented and statically validated; fresh manual Ableton open pending
Date: 2026-08-02
Scope: Live 11.3 current-path copy

## Problem

The desktop copy pipeline previously copied every observed audio file to
`Samples/Imported`, but authorized rewrite only for `RelativePathType = 1`.
Existing Type 3 references were recorded as non-blocking omissions. This could
produce a package containing copied audio that no active output reference used.

## Accepted Ruleset

`live11_3_current_paths_v0.2-lab` contains exactly two rules:

```text
Type 1 external:
  target = Samples/Imported/<safe filename>
  change = Path, RelativePath, RelativePathType
  new type = 3

Type 3 project-local:
  precondition = safe RelativePath under Samples/...
  target = preserve the same RelativePath
  change = Path only
  RelativePath and RelativePathType remain unchanged
```

Only confirmed Live 11.3 `AudioClip` and `MultiSamplePart` structures are
admitted. Other contexts, unsafe paths and unsupported types block before
staging. Only genuinely missing current-path assets may remain non-blocking.

## Automated Evidence

Tests cover:

```text
Type 3 AudioClip reader handoff
Type 3 MultiSamplePart reader handoff
unsafe project-relative traversal rejection
mixed Type 1 and Type 3 planning
no copied audio without an approved resolving reference

```

All workspace tests, clippy, TypeScript, Vite, module guards and the macOS Tauri
application build pass.

## Read-Only Real-Project Preview

One large private Live 11.3 project was evaluated without writing a package or
modifying any source. Private paths and filenames were not retained.

```text
required assets: 1190
planned audio copies: 1190

Type 3 Path-only operations: 1467
omitted assets: 0
```

The remaining one reference used the existing external Type 1 rule. Five Type
3 references were structurally recognized as multisample references.
