# Intake

Tu mozna wrzucac surowe materialy do przetworzenia:

```text
dlugie rozmowy z GPT
chaotyczne notatki
transkrypcje
listy pomyslow
```

To jest folder tymczasowy.

Material z `intake/` powinien zostac przetworzony przez Product Office do:

```text
session-digests/
```

Nie kazda rozmowa musi byc zapisywana w `intake/`.

Uzywamy tego tylko wtedy, gdy material jest dlugi albo warto zachowac surowe zrodlo.
