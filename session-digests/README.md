# Session Digests

Tu trafiaja przetworzone rozmowy.

Cel:

```text
z dlugiej rozmowy wyciagnac decyzje, hipotezy, pytania, ryzyka i nastepny krok
```

Nazwa pliku:

```text
YYYY-MM-DD_short-topic.md
```

Przyklad:

```text
2026-06-01_one-codex-thread-product-office.md
```

Digest nie jest specyfikacja.

Digest jest pomostem:

```text
rozmowa -> klasyfikacja -> decyzja co zapisac dalej
```
